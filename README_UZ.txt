JARVIS Android - 1-bosqich

Bu hozircha APK emas, telefon bosh ekraniga o‘rnatiladigan PWA boshlang‘ich versiyasi.

Ishlaydigan imkoniyatlar:
- Matnli buyruq
- Brauzer qo‘llasa, ovozli buyruq (uz-UZ)
- Javobni ovoz chiqarib o‘qish (telefon ovozlari mavjudligiga bog‘liq)
- Soat va sana
- Google va YouTube havolalarini ochish

Hozircha mavjud emas:
- Haqiqiy AI modeli bilan suhbat
- Doimiy "Hey Jarvis" tinglash
- Telefonning barcha ilovalarini yashirin/cheksiz boshqarish
- Kompyuterni masofadan boshqarish

Tez sinash:
1. ZIP ichidagi fayllarni oching.
2. Fayllarni HTTPS orqali hostingga joylash kerak (masalan GitHub Pages).
3. Android Chrome'da saytni oching.
4. Chrome menyusi (⋮) > "Add to Home screen" / "Install app".
5. Mikrofon so‘ralsa ruxsat bering.

Eslatma: PWA'ni oddiy file:// orqali ochish mikrofon va Service Worker uchun ishlamasligi mumkin.
Keyingi bosqichda hosting va AI backend ulash kerak. API kalitini hech qachon HTML/JS ichiga joylamang.
